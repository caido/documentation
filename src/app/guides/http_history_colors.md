# Applying color to HTTP History table rows

To highlight requests in HTTP History right-click the row for the request you want to highlight. In the context menu, open **Highlight** and choose a color.

<img alt="Highlight Color menu" src="/_images/http_history_highlight_menu.png" center>

The request row now appears in the selected color.

<img alt="Highlight Request in selected color" src="/_images/http_history_highlighted_request.png" center>
