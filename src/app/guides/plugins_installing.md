# Installing Plugins

To install a plugin, either:

- **Click** on the <code><Icon icon="fas fa-upload" /> Install Package</code> button and select a plugin `plugin_package.zip` file.
- Or **click** on the `+ Install` button associated with a plugin available in the Community Store.

::: warning
Plugins available in the Community Store run third-party code, which could potentially pose security risks. Before you can access the Community Store, you must **click** on the _"I understand the risks associated with third-party plugins."_ checkbox to acknowledge and accept the risk.

:::

## Browse Plugins

The Plugins page helps you discover and compare plugins before installing them.

- Look for the Official badge to identify plugins maintained by Caido.
- Review each row's quality rating, author, download count, and version.
- Use the Official and Community filters to narrow the list.
- Select multiple plugins, then install or update them in one action.
