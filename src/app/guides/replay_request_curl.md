# Using Curl to send Replay Request

Click the <code><Icon icon="fas fa-chevron-down" /></code> dropdown next to `+ New Session` and select <code><Icon icon="fas fa-terminal" /> From cURL</code>.

<img alt="Creating a new Curl Replay Session." src="/_images/replay_curl.png" center width=350>

Paste your cURL command into the `New Session from cURL` window.

<img alt="Curl context menu Replay Session." src="/_images/replay_curl_menu.png" center width=350>

Click Create to open a new Replay session with the imported request.

<img alt="Curl created request for Replay." src="/_images/replay_curl_newSession.png" center>
